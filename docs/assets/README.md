# Studio asset provenance

Studio Small 09, by Sergej Majboroda, comes from [Poly Haven](https://polyhaven.com/a/studio_small_09), released under [CC0](https://polyhaven.com/license). The 1K HDR is bundled locally; manifest.json records its source, size and SHA-256.

Furniture, botanical geometry, oak, fabric, leaf and rug textures are original source assets authored in office-furniture.js and office-materials.js. Staff remain articulated stylized models, not scanned or photorealistic people. The Xarts logo remains local-only and is not included here.
