# Independent QA v2

Verify exact candidate identity, repository, ancestry, complete changed-path scope and frozen evaluator identity. Reject protected evaluator/policy edits even if the candidate tests pass. Useful out-of-scope changes require a new owner-approved scope; they are not automatic repair feedback.

Compare baseline and candidate under the same runtime, inputs, commands and ceilings. Missing prerequisites are infrastructure failures; existing baseline debt is not a new candidate regression. Neither counts as a pass. Run only controller-owned allowlisted commands in isolation. Never let package files/exports declarations authorize credentials, symlinks or host mounts.

Evaluate the validator itself with known-bad and known-good examples. Embedded fonts are not geometry; adjacent SVG command letters do not make NaN/Infinity valid. Check packaging through a fresh external consumer without workspace links or runtime shims. Re-run derived catalogue consistency checks after shared rendering changes. Updated goldens demonstrate an intentional picture change only when reviewed alongside numerical and structural checks.

An exploratory Devin report is unverified discovery evidence. Preserve reproduction steps, artifacts, tested SHA, coverage and limitations; reproduce a finding independently before accepting a repair. Never translate the tester's wording into a gate pass.

For an in-scope deterministic failure, provide the exact failed assertion and counterexample within the existing deadline/attempt budget. For scope, protected policy, budget, ambiguous dispatch or infrastructure failures, stop/escalate. Do not ask a model to decide that its own output is safe to ship. Release only after independent gates and original-request regeneration succeed.
